 🔑 Premier accès web — 2 options
═══════════════════════════════════════════════════════════════════════════════

OPTION A (recommandée) — Password saisi via form POST :

  1. Va sur : https://{{ .Values.ingress.hostname }}/login-password
  2. Ton password est visible dans Onyxia UI :
       Mes services > qgis-hub > "Values de Helm" > security.password
  3. Copie-le, colle-le dans le form, clique "Se connecter"
  4. Cookie hub_api_key 90j auto-set → workspace accessible

  Sécurité : password envoyé en POST body (jamais en URL, jamais dans logs).

OPTION B (secours) — Token OIDC SSPCloud :

  1. Va sur : https://{{ .Values.ingress.hostname }}/onboarding
  2. Colle ton id-token depuis https://datalab.sspcloud.fr/account/k8sCodeSnippets
  3. Cookie posé automatiquement

═══════════════════════════════════════════════════════════════════════════════
 🔧 Récupérer ton password via kubectl (en secours)
═══════════════════════════════════════════════════════════════════════════════

Si tu ne peux pas ouvrir Onyxia UI, récupère depuis le Secret Helm :

  kubectl get secret sh.helm.release.v1.qgis-hub.v1 -n {{ .Release.Namespace }} \
    -o jsonpath='{.data.release}' | base64 -d | base64 -d | gunzip \
    | jq -r '.chart.values.security.password'

Ou depuis les env vars du pod hub :

  kubectl exec -n {{ .Release.Namespace }} qgis-hub-0 -- printenv SECURITY_PASSWORD
