### Accès au service

- Ouvre QGIS Service dans ton navigateur avec [ce lien](https://{{ .Values.ingress.hostname }}/login).
{{- if (.Values.security).apiKey }}
- Ta clé d'accès : `{{ (.Values.security).apiKey }}`
{{- else }}
- Ta clé d'accès n'est pas affichée ici (tirage automatique). Récupère-la avec :
  `kubectl get secret qgis-hub-apikey -n {{ .Release.Namespace }} -o jsonpath='{.data.HUB_API_KEY}' | base64 -d`
{{- end }}

Colle cette clé dans le formulaire : elle est envoyée en corps de requête,
jamais dans l'URL. Un cookie de 90 jours est posé — tu ne repasseras plus
par cette étape pendant trois mois, y compris après fermeture du navigateur.

Cette même clé sert au connecteur MCP (Claude Desktop, Cursor, Cline) :
récupère la configuration prête à copier sur
https://{{ .Values.ingress.hostname }}/auth/apikey

Si tu perds la clé, elle reste affichée sur cette page. En dernier recours,
https://{{ .Values.ingress.hostname }}/onboarding accepte un jeton OIDC
SSPCloud (datalab.sspcloud.fr > Mon compte).

═══════════════════════════════════════════════════════════════════════════════
 🤖 Cle LLM (agent IA)
═══════════════════════════════════════════════════════════════════════════════

{{- if .Values.llm.apiKey }}
✅ Cle IA deja configuree (reprise de ton profil SSPCloud).
   L'assistant est operationnel, rien a faire.
{{- if .Values.llm.model }}
   Modele : {{ .Values.llm.model }}
{{- end }}

Pour en changer : https://{{ .Values.ingress.hostname }}/workspace
bloc "Cle LLM (agent IA)".
{{- else }}
Aucune cle IA n'a ete trouvee dans ton profil SSPCloud. Sans elle,
l'assistant ne peut pas repondre.

  1. Recupere une cle sur https://llm.lab.sspcloud.fr (onglet API keys)
     -- ou renseigne ton profil : datalab.sspcloud.fr > Mon compte >
     Assistant IA, puis relance l'installation.
  2. Va sur https://{{ .Values.ingress.hostname }}/workspace
  3. Ouvre le bloc "Cle LLM (agent IA)", colle la cle, Enregistrer.
{{- end }}

La cle est conservee dans un Secret Kubernetes de ton espace : elle
survit aux redemarrages de pod et aux mises a jour du service.
